## 本轮设计规范与 UI 交互范围

本轮在已有视觉改版基础上，将参考取证、统一规范和当前代码采用值集中到根目录 [design.md](../../design.md)。参考材料包括即梦公开 HTML/CSS、无登录桌面截图、侧栏展开/收起/悬停，以及真实参数浮层和导航提示的测量。规范分别标明参考事实、项目采用值和未确认状态，保留旧 CSS 与当前页面标题字级的冲突，使用当前渲染结果作为工作室标题依据。

- 基础样式统一到全局语义 token，涵盖暗色页面、表面、文字、透明描边、白色主按钮、蓝色焦点与功能反馈色；普通页面标题24/32左对齐，工作室标题桌面30/38居中，移动降为24/32。系统字体和自有品牌尺寸属于明确的项目适配。
- 桌面侧栏采用240/64两种宽度，展开品牌行右侧提供收起入口，收起后品牌区悬停显示展开图标；导航选中态、图标、文字、tooltip共用规范。桌面折叠偏好恢复与移动抽屉状态分开处理。
- 移动侧栏采用抽屉、遮罩、背景不可交互及焦点控制；侧栏打开时锁定页面滚动，关闭后返回菜单触发器。普通页、工作室和编辑阶段按各自业务布局使用共享间距与断点。
- 共用 Dialog 与 Popover 承载删除与清缓存确认、剧集参数、生成配置、素材选择、图片预览、任务中心和设置菜单。统一圆角、背景、阴影与组件字级，保留适合内容的命名尺寸/内边距变体；菜单默认8px，集数表单16px，生成配置12px，移动弹窗内容20px。
- 浮层交互覆盖外部点击、Escape、焦点返回、滚动锁定或长列表内部滚动；Popover计算锚点位置并处理视口边界。共享组件的代码路径与页面调用点都需要在本轮浏览器验证中核对。
- 通用按钮覆盖default/hover/pressed/disabled/loading，危险确认使用独立反馈色；输入、分段筛选、空状态、加载、错误与toast使用同一套语义样式。分段筛选按当前原生按钮与aria-pressed语义记录，不冒称已经实现完整tablist方向键状态机。
- 侧栏设置菜单保留配置入口与已有清缓存操作，清缓存使用明确确认弹窗及结果提示。视觉统一不改变后端接口、任务契约、生成计费路径或已有人工确认边界。
- 当前已记录的适配差异包括自有logo尺寸、导航行高、输入高度组合、桌面侧栏偏好断点、移动点击尺寸、toast圆角和表单浮层内边距。参考站未成功展开的更多设置菜单不作为浮层取证成功证据；真实参数popover证据另行关联。

本节记录本轮范围和实现约束，不填写本轮验收计数，也不据此宣布阶段完成。本轮测试、截图、差异检查、阶段闸门和剩余事项由本轮证据包与项目状态文件补充。
