# 技术文档目录说明

本目录按 **PRD 版本** 归档，一个版本一个父级目录，避免多版本文档混在一起分不清。

## 目录结构约定

```
docs/
└── <PRD版本>/                     # 与 PRD/<PRD版本>.md 同名
    ├── 技术适配声明.md
    ├── 阶段N-第X批-技术开发文档.md
    └── evidence/
        └── 阶段N-第X批-证据包.md
```

## 新增版本时

1. PRD 放到 `PRD/<新版本>.md`
2. 技术文档放到 `docs/<新版本>/`
3. 按上面的结构建「技术适配声明 + 阶段技术开发文档 + evidence」
