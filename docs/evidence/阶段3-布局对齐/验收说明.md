# 页面边距与滚动对齐验收

2026-09-24。唯一修改对象为 `project/DramaCoo`。

## 统一后的规则

| 视口宽度 | 左右页面边距 |
| --- | --- |
| ≥1024px | 40px |
| 768–1023px | 24px |
| <768px | 16px |

以上间距以主滚动区域的可用宽度为基准，不把系统滚动条当作内容空间。页标题、首页输入卡外框与灵感区、创作顶部栏、正文和底部按钮都共用 `--layout-gutter`。卡片内部文字padding仍独立保留，不能与外边距混为一谈。

- 移除普通页1400px、首页1200px、输入卡1010px三套独立宽度上限和居中外边距。
- 全站使用同一个主滚动区，滚动条预留空间保持稳定；不再出现某个阶段正文单独多出6px的情况。
- 创作顶部栏和底栏都在主区域内保持可见，随侧栏一起变化，不各自计算固定偏移。
- 打开/关闭弹窗或手机抽屉，背景左右边线不动；弹窗头部、内容和底部共享滚动宽度。
- 页面或创作阶段切换返回顶部，任务进度和后台数据刷新保留当前阅读位置。
- 按实际顶部栏与底栏高度保留滚动安全空间，窄屏运行控件可换行。
- 页面加载骨架也使用同一容器，不再出现加载时临时换一套边距。

## 修改前后的实测

下表是内容左边界距离主区域左边缘的CSS像素；输入卡按外框测量。

| 场景 | 修改前 | 修改后 |
| --- | ---: | ---: |
| 1512px 展开，工作室灵感区 | 73 | 40 |
| 1512px 展开，工作室输入卡 | 128 | 40 |
| 1512px 展开，项目库 | 40 | 40 |
| 1512px 收起，项目库 | 64 | 40 |
| 1920px 展开，工作室灵感区 | 277 | 40 |
| 1920px 展开，工作室输入卡 | 332 | 40 |
| 1920px 展开，项目库 | 180 | 40 |
| 1920px 收起，项目库 | 268 | 40 |
| 桌面创作顶部栏 | 16 | 40 |
| 桌面创作正文与底栏 | 40 | 40 |

自动化以 `main.rect.left + main.clientLeft + gutter` 计算左边线，以主容器 `clientWidth` 计算右边线；允许误差≤1px，本次所有测量中的最大边线误差为 **0px**。本机可见滚动条实际占6px，各页面统一预留；代码未把6px写死，其他系统按实际滚动条宽度计算。

## 自己查看

1. 打开预览，依次点击工作室、项目库、素材库、临时工作台、动作迁移和设置。各页面主内容距侧栏应相同。
2. 收起侧栏，切换相同页面；再展开，确认不再出现某页额外居中的情况。
3. 从项目库打开已有项目，点击剧本。顶部第一项、正文左边和底部首个按钮应对齐；向下滚动，底部内容应能完整到达。
4. 滚到长页面底部后点击另一创作阶段，应回到新阶段顶部。
5. 打开设置菜单中的清空缓存确认框，只查看后按Escape取消。背景页面的宽度和边线应保持不变。
6. 缩小到手机宽度，检查菜单抽屉、创作工具条与底部按钮。无需生成或删除任何内容。

可复跑命令见[前端README](../../../frontend/README.md)。日志和原始自动化报告保存在本地 `/tmp`，不混入截图证据包。
