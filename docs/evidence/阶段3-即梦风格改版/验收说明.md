## 查看改版

打开 [改版工作室](http://127.0.0.1:3004)。原 3002 服务仍运行旧构建，本轮用 3004 独立预览。

1. 侧栏应有工作室、项目库、素材库、临时工作台、动作迁移和设置；不再有文艺短视频、数字人口播入口。
2. 工作室向下浏览，灵感卡片之后不再有首页历史记录。已有项目继续从项目库打开。
3. 打开 [临时工作台](http://127.0.0.1:3004/sandbox)、[动作迁移](http://127.0.0.1:3004/pipelines/action-transfer)、[设置](http://127.0.0.1:3004/settings)，标题和描述在左上角，与项目库一致。
4. 页面应使用统一深灰背景、暗色面板、白色主按钮、灰色选中导航和浅色文字。生成配置、素材选择、图片预览及项目内阶段页面使用相同颜色变量。
5. 将窗口缩窄检查侧栏关闭后内容可操作、标题自动换行、模型弹窗不出屏。手机下图片缩略图可横滑，项目内顶部阶段与操作分两行。
6. 打开已有项目并刷新，应继续恢复相同项目。本轮不会自动发起收费生成或删除数据。
