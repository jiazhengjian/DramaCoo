## 本轮变更

- 导航保留工作室、项目库、素材库、临时工作台、动作迁移和设置；工作室首页无历史记录模块。旧任务路由继续可用。

- Dialog、Popover、Toast、危险确认共用实现，覆盖焦点约束与返回、Escape、外部点击、滚动锁定、视口碰撞和移动适配。
- 补齐项目/素材/配置/任务历史的加载、空态、失败重试；模型列表失败保留当前选择；JSON格式错误阻止提交并保留输入；保存和删除失败有反馈。

## 手工复核步骤

1. 打开预览，点击品牌右侧收起按钮。应保留64px图标栏；悬停品牌区后点击展开，恢复240px。刷新后保持桌面选择。
2. 打开项目库、临时工作台、动作迁移、设置，观察左上标题基线、表单、主按钮和卡片层级。工作室底部应没有历史记录模块。
3. 在工作室打开集数设置，按Escape关闭；在项目库打开删除确认后点击取消。弹层关闭后焦点应回到触发按钮。无需实际删除项目。
4. 将浏览器宽度改为390px，打开左上菜单，再按Escape关闭。背景在菜单打开时不可滚动/操作，关闭后恢复。
5. 需要查看错误和加载样例时，直接打开对应截图或运行前端README中的自动化命令，不必破坏真实服务制造失败。
